# Impeccable — product website concept decision

The existing desktop app's identity ("Quiet Control Room") is binding; the public website is a distinct **Persuade** surface. All variants preserve factual product claims, marine blue and teal accents, verified application screenshots, keyboard accessibility, and light-first presentation.

## Concept A — Interface, made tangible (selected)

Strong restrained typographic hero and actual macOS product frame. Controlled dark shell in the hero, not a permanently dark website. The interface screenshot has editorial prominence. A slim curl example reinforces the product's practical usefulness. The narrative runs from personal control to browser workflow to API call, then limitations. This is the selected implementation because it explains the local trust boundary immediately.

## Concept B — Developer's workbench

A left-hand annotated terminal process flow opens the homepage; smaller product screenshot to the right. More terminal-focused and code-first, but the product looks less like a polished desktop application. Better for an API-only library than a Mac application.

## Concept C — A quiet window

Full-bleed light neutral background with oversized native UI crop and short story captions. Editorial calm, exceptional screenshot visibility, but the API's developer value requires more scrolling.

## Implementation contract

- Purpose: developer adoption and qualified downloads; no paid plan, fake social proof, or unverified availability.
- Content: independent/unofficial local browser automation, Apple Silicon first, browser login by user, localhost bridge, Chrome and Playwright CLI required.
- Modes: light default, user dark preference persisted on device, reduced motion respected.
- Breakpoints: desktop (1440), tablet (768), mobile (390); screenshots must scale without lost callouts.
- GitHub Pages: all routes pre-rendered and project-repository base path supported.
- Initial release mode: no published release is verified. No active download CTA until a release asset is published and reviewed.
- A dedicated video is not available in the repository; use real screenshots with accessible explanatory content instead of a fabricated recording.
